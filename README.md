## Overview

**Edu Chat** is an AI chat interface specifically designed to provide a **safe and private environment for education**. By leveraging [WebLLM](https://github.com/mlc-ai/web-llm) and WebGPU technology, it runs large language models (LLMs) natively and entirely within your browser. 

This means:
- **Privacy First**: Conversations are processed locally on your device. Data never leaves your computer.
- **No Servers Required**: No need for API keys or remote server subscriptions for the core experience.
- **Safe for Schools**: Ideal for educational settings where data privacy and student safety are paramount.

## Key Features

- **Local Inference**: Harnesses the power of WebGPU for high-performance AI without cloud dependency.
- **Private & Secure**: Perfect for students and teachers to experiment with AI in a controlled, private space.
- **Galician Language Support**: We have proudly added full support for the **Galician language (`gl`)**, ensuring accessibility for the Galician educational community.
- **Multilingual UI**: Supports English, Spanish, Galician, and many other languages.
- **PWA Support**: Can be installed as a progressive web app for a native-like experience.

## Getting Started

To run Edu Chat locally for development:

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Visit [gallego.top/educhat](https://gallego.top/educhat) to use the deployed version.

## Built-in Models

Edu Chat supports a wide range of WebLLM built-in models, including Llama 3, Phi-3, Gemma, and more. You can find the full list of supported models in the settings menu.
